# 旁白脚本与读音

## 脚本结构（script.py）

```python
SCRIPT = [
("intro", "序章", ["句子1", "句子2"]),
("embed", "03 · 词嵌入", [
    "普通句子：字幕 = 朗读。",
    ("字幕写 T×768 的矩阵", "朗读写 T 乘 768 的矩阵"),   # 二元组：(字幕, 朗读)
]),
]
```

- 一个场景 3~8 句；每句 15~60 字。每句就是一个动画时间锚点（`S.c(i)`），所以**按“画面要变化的位置”断句**。
- 章节标签形如 `"07 · 自注意力：Q K V"`，序章、总结不编号。
- 时长参考：中文 YunxiNeural +6% 约 5.3 字/秒；4000 字旁白 ≈ 13 分钟成片。

## 内容写法（科普讲解风格）

- 先提问 / 讲动机，再讲做法，最后讲细节和坑。
- 抽象概念配一个**贯穿全片的小例子**（"The cat sat on the"、"ababab"、"hii there"），数字前后一致。
- 能用真实运行结果就用真实结果（自己跑一遍代码拿数字）；无法跑的数值在画面上标“示意”。
- 用户给的材料若比较简略，要主动扩充：原理、为什么这么设计、常见误区、和上下游的衔接。
- 结尾：一张全流程回顾图 + “我们下期见”。

## 读音处理（say.py 自动执行，tts.py 调用）

处理顺序：英文术语表 EN → 多音字表 POLY → “行”消歧 → 符号（× ≈ √ = %）→ 数字转中文 → 清理空格。

1. **数字**：字幕里直接写阿拉伯数字，`say()` 自动转中文读法（768→七百六十八，1.24→一点二四，90%→百分之九十，“2 次/个/轮…”→“两次”）。
   - 年份要手写朗读文本：`("2017 年", "二零一七年")`。
   - 代码/编号串（`[46, 47, 47]`）会被逐个读成中文数字，通常可接受；太长就在朗读文本里改写。
2. **英文**：Yunxi 能读常见英文单词，但下列情况必须拆：
   - 驼峰 / 连写：`LayerNorm→Layer Norm`、`softmax→soft max`
   - 下划线、点号、括号：`zero_grad()→zero grad`、`loss.backward()→loss 点 backward`（say.py 已自动把 `a.b` 读成“a 点 b”、去掉 `()` 和 `_`）
   - 全大写缩写会逐字母读（FFN、BPE、GPT），这通常就是想要的；不想逐字母读就写成单词
   - 小写缩写要改成大写并加空格：`stoi→S to I`、`d_k→D K`
   - 带连字符的版本号：`GPT-2→GPT 二`
   - 拿不准的词（如 ReLU）宁可逐字母读：`R E L U`
3. **多音字**：把有歧义的字换成**读音唯一的同音字**，只改朗读、不改字幕：
   - 内置：残差/方差/标准差/误差 → 插；奇数→基数；累加→垒加；学习率→学习律；行（háng）→航（保留“进行/执行/并行…”等 xíng 词）；重叠/重新→虫；还原→环原；调用→掉用；差距→插距
   - 写稿时**主动避开**：“得”作“必须”讲（改“要”）、“当成”（改“看作”）、“分量”（改“元素”）、“转速”、“朝着”、“倒数”
   - 项目特有的放 `config.py` 的 `EXTRA_POLY` / `EXTRA_EN`
4. 写完脚本后，**把所有朗读文本打印出来通读一遍**：
   ```bash
   venv/bin/python -c "
   from script import SCRIPT; from say import say
   for sid,l,ss in SCRIPT:
     for s in ss: print(sid,'|',say(s if isinstance(s,str) else s[1]))"
   ```
   重点检查：残留的阿拉伯数字、`_`、奇怪的“航”（如“换行”会变“换航”，读音正确，没问题）。
5. 可选：`asr.py` 用 faster-whisper 把生成的语音转写回文字做粗查（需要额外安装 faster-whisper，HF 走镜像 `HF_ENDPOINT=https://hf-mirror.com`；对多音字检查能力有限，主要抓英文读错）。

## 字幕

make.py 的 `split_sub()` 自动把每句切成 ≤ ~26 字的字幕块，按字数比例分配时长：
- 只在中文标点处断句（英文逗号常在代码/元组里，不能断）
- 超长句子在不拆英文单词、不拆括号内容的位置硬切
字幕显示的是二元组里的**字幕文本**。
